One page that runs an entire webinar program.

I built a tool that turns a team's messy planning notes into a complete, tracked webinar campaign: the brief, every UTM, every email, the recording page, the knowledge base article, and a checklist so nothing gets skipped. In production it cut end-to-end webinar time by more than two-thirds.

This public version uses a made-up company (Brightwell Learning) and simulated results. The real tool's company data, content and integrations aren't included.
